# you talk

> **YouTube 영상을 다시 돌려보는 대신, 필요한 순간을 근거와 함께 찾아 대화합니다.**

![you talk 서비스 소개 화면](assets/you-talk-landing.png)

## 왜 만들었나요?

나중에 보려고 저장한 영상은 계속 쌓이지만, 다시 찾아볼 때는 늘 같은 문제가 반복됩니다.

- 필요한 내용이 어느 영상에 있었는지 기억나지 않습니다.
- 긴 영상에서 원하는 부분을 찾으려면 앞뒤로 계속 돌려봐야 합니다.
- AI에게 질문해도 답변이 영상의 어느 부분에서 왔는지 확인하기 어렵습니다.

**you talk**는 영상을 주제별로 모으고, 필요한 영상만 분석한 뒤, 질문에 대한 답과 실제 영상 근거를 함께 보여주는 서비스입니다.

## 이렇게 사용합니다

1. **영상 링크를 넣습니다.** 영상 제목을 기준으로 폴더가 만들어지고, 이후 관련 영상을 같은 공간에서 관리합니다.
2. **필요한 영상을 분석합니다.** 자막을 우선 활용하고, 자막이 없으면 음성을 텍스트로 변환합니다.
3. **영상에 대해 질문합니다.** 답변과 함께 해당 내용이 나온 타임스탬프 구간을 확인하고, 바로 그 시점으로 이동할 수 있습니다.

## 핵심 경험

| 기능 | 사용자에게 주는 가치 |
| --- | --- |
| 폴더 중심 영상 관리 | 주제별로 영상을 모아두고, 다음에 다시 찾기 쉽게 만듭니다. |
| 선택 분석 | 모든 영상을 무조건 깊게 분석하지 않고, 필요한 영상부터 분석합니다. |
| 근거 기반 대화 | 답변만 주지 않고 실제 자막 구간과 YouTube 시간 링크를 함께 제공합니다. |
| 근거 표시 모드 | 구간만 빠르게 보거나, 질문과 가까운 핵심 문장까지 확인할 수 있습니다. |
| 영상별 대화 | 다른 영상의 대화가 섞이지 않아, 영상마다 맥락을 이어서 질문할 수 있습니다. |
| 답변 재사용 | 답변 듣기와 TXT/PDF 내보내기로 읽은 내용을 다시 활용할 수 있습니다. |

## 서비스 원칙

**영상 전체를 대신 보는 서비스가 아니라, 사용자가 필요한 부분에 더 빨리 도착하게 하는 서비스**를 지향합니다.

그래서 채널과 영상의 metadata로 먼저 탐색 범위를 만들고, 선택한 영상만 자막·텍스트 분석·의미 검색까지 진행합니다. 질문할 때는 분석된 영상 안에서 관련 구간을 찾고, 답변의 근거를 사용자가 직접 검증할 수 있도록 합니다.
